# IteraMath U2

Aplicación de la unidad 2, con la misma pantalla de IteraMath: método a la izquierda y, a la derecha, resumen, gráfica, tabla y código de Octave.

Incluye sistemas directos e iterativos, Newton y punto fijo para sistemas, Lagrange, Newton por diferencias divididas, y regresión polinomial y múltiple.

```bash
npm install
npm run dev
npm test
```
